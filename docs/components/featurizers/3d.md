# 3D Descriptors

Descriptors computed from 3D conformers. All nine have `requires_conformers=True`, so conformers are generated automatically during featurization.

| Name | What it is | Dimension / defaults | Storage dtype |
|------|-----------|----------------------|---------------|
| `whim` | WHIM weighted holistic invariant descriptors | 114 | `float32` |
| `usr` | Ultrafast shape recognition | 12 | `float32` |
| `usrcat` | USR with CREDO atom types | 60 | `float32` |
| `e3fp` | E3FP extended 3D fingerprint (binary) | `fp_size=2048`, `level=5`, `radius_multiplier=1.718` | `packed_uint8` |
| `getaway` | GETAWAY geometry, topology and atom-weights assembly | scikit-fingerprints default | `float32` |
| `morse` | MoRSE electron-diffraction representation | scikit-fingerprints default | `float32` |
| `rdf` | Radial distribution function | scikit-fingerprints default | `float32` |
| `autocorr` | 3D autocorrelation | scikit-fingerprints default | `float32` |
| `electroshape` | ElectroShape electrostatic shape | 15 | `float32` |

## Conformer defaults

Every 3D featurizer defaults to `num_conformers=1`, `optimize_force_field='MMFF94'` and `random_state=0xf00d` (the seed for conformer generation, so results are reproducible and different seeds get different cache entries). Override them with `create_featurizer`:

```python
from learnm8.features import create_featurizer

featurizer = create_featurizer('whim', num_conformers=3)
```

## Usage

```bash
learnm8 run compounds.csv --target Activity --learner rf --featurizer usrcat
```

```python
from learnm8 import extract_features

features = extract_features(['CCO', 'c1ccccc1'], 'usr')
```

See the [featurizers overview](overview.md) for the other categories.
